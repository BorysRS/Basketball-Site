# Basketball Website

My first ever website created using HTML and CSS - without AI :)

Features:
-Sticky bar at the top of the screen that helps you navigate through the site.
-Responsive layout (Works well on phones).
-Hover animations when cursor lands on: Player cards, Team cards, Navigation on top-bar, On button "Dowiedz się więcej" and more.
-Clicking on player or team names sends you to their Wikipedia page.
-CSS styling.

The images should be in the same folder as HTML and CSS files.

(The website is in Polish)
